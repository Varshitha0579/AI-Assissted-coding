# 💰 Budget Allocation Helper

A simple and interactive web tool that helps users divide a total budget
into different categories based on percentages. The tool dynamically
calculates the amount allotted to each category and helps in efficient
financial planning.

## 🚀 Features

-   Enter a total budget amount
-   Add unlimited custom categories
-   Assign percentage values to each category
-   Automatic calculation of funds per category
-   Remove categories instantly
-   Error alert if percentages do not sum to 100%
-   Clean, attractive, responsive UI

## 🛠 Tech Stack

  Technology   Purpose
  ------------ ------------------------------------------
  HTML         Structure of the web page
  CSS          UI styling and layout design
  JavaScript   Calculations & dynamic category handling

## 📌 Project Objectives

-   Help users plan financial budgets efficiently
-   Automate calculations to avoid manual mistakes
-   Provide an intuitive and user-friendly experience
-   Allow dynamic category customization
